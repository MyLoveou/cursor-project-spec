> 位于规范库根 `templates/`。Bootstrap 时复制到业务项目。

| 模板 | 复制到 |
|------|--------|
| `AGENTS.md.template` | `<项目>/AGENTS.md` |
| `docs-requirements-feature.md.template` | `docs/requirements/features/<id>/需求.md` |
| `docs-feature-design.md.template` | `docs/requirements/features/<id>/设计.md` |
| `docs-implementation-plan.md.template` | `docs/requirements/features/<id>/实现方案.md` |
| `agents/*.md.template` | 参考用；运行时见 `agents/*.md` |
| `rules/*.mdc.template` | 参考用；运行时见 `rules/` |
| `evals/*.md.template` | 参考用；运行时见 `shared/evals/` |

见 [BOOTSTRAP.md](../BOOTSTRAP.md)、[STRUCTURE.md](../STRUCTURE.md)。
