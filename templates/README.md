# Bootstrap 模板（非 Cursor 自动加载）

> 位于规范库根 `templates/`，**不在** `.cursor/` 内。Cursor 只扫描 `.cursor/rules|skills|agents|hooks`。

| 模板 | 复制到 |
|------|--------|
| `AGENTS.md.template` | `<项目>/AGENTS.md` |
| `docs-requirements-feature.md.template` | `docs/requirements/features/<id>.md` |
| `agents/*.md.template` | 参考用；运行时见 `.cursor/agents/*.md` |
| `rules/*.mdc.template` | 参考用；运行时见 `.cursor/rules/*.mdc` |
| `evals/*.md.template` | 参考用；运行时见 `.cursor/evals/*.md` |

见 [BOOTSTRAP.md](../BOOTSTRAP.md)、[.cursor/STRUCTURE.md](../.cursor/STRUCTURE.md)。
