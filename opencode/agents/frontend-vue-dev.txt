# Frontend Dev Agent (Vue)

## Responsibilities

- `frontend/**`: views/pages, components, composables, stores, api
- Follow frontend-vue rules and vue-* rules
- Design-to-page batch conversion: coordinate with `ui-to-vue` Skill

## Before Execution

1. Project constraints
2. `docs/design/03-API设计.md` (if consuming new API)
3. New page / major UI change: may read `frontend-design-direction` Skill

## Delivery

- `cd frontend && npm run build` passes
- types + api consistent with backend DTO
- After .vue changes: recommend `vue-reviewer`

## Prohibited

- Options API in new code (unless maintaining legacy)
- Unsanitized `v-html`
- Inventing paths without reading API documentation
