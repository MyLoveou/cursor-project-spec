# TDD Command

Execute the Test-Driven Development workflow.

## Instructions

1. Write failing tests first that define expected behavior
2. Verify tests fail (RED phase)
3. Write minimal implementation to pass tests (GREEN phase)
4. Verify tests pass
5. Refactor while keeping tests green (IMPROVE phase)
6. Confirm 80%+ coverage across unit, integration, and E2E tests

Cover edge cases: null, empty, invalid input, error paths, boundary values.
