# Build Fix Command

Diagnose and fix build, type, and compilation errors.

## Instructions

1. Run the build command and capture all errors
2. Categorize errors: type, import, config, dependency
3. Apply minimal, surgical fixes — no refactoring or architectural changes
4. Fix one error at a time, re-run build after each fix
5. Verify tests still pass after all fixes

DO NOT: refactor code, change architecture, suppress errors, or add features.
