# Update Docs Command

Update documentation and codemaps to match current codebase.

## Instructions

1. Analyze codebase structure and identify stale documentation
2. Update API design docs when endpoints change
3. Update data model docs when entities/migrations change
4. Create ADRs for architectural decisions
5. Update capability docs and roadmap for scope changes
6. Verify all file paths, links, and code examples are valid

Do not bulk-rewrite README without explicit request.
