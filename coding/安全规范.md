# 安全规范（通用）

> 来源：ECC [rules/common/security.md](https://github.com/affaan-m/everything-claude-code/blob/main/rules/common/security.md)

---

## 1. 提交前检查

- [ ] 无硬编码密钥（API key、密码、token）
- [ ] 用户输入已校验
- [ ] SQL 使用参数化查询（ORM/JPA 参数绑定）
- [ ] XSS：输出转义；富文本需 sanitize
- [ ] 鉴权/授权已验证
- [ ] 错误响应不泄露敏感信息（栈、路径、SQL）

---

## 2. 密钥管理

| 规则 | 说明 |
|------|------|
| 禁止 | 密钥写进源码并提交 |
| 推荐 | 环境变量、密钥管理服务 |
| 启动 | 校验必需 secret 已配置 |
| 泄露 | 立即轮换 + 排查同类问题 |

**.gitignore 常见项**：`.env`、`*.pem`、`backend/data/`、本地数据库文件。

---

## 3. 认证常见模式

| 模式 | 要点 |
|------|------|
| JWT | access / refresh **分离**；refresh 不可当 access |
| Bearer | `Authorization: Bearer <token>` |
| Session | CSRF 防护（若用 cookie） |

具体 RBAC 角色由**项目**定义（见项目 `docs/design/`）。

---

## 4. API 安全

- 敏感操作需登录 + 权限校验（不仅「已登录」）
- 分享/邀请链接 token 不可预测
- 未实现端点：返回 **501**，勿伪造 200
- 生产环境：Rate limiting（本地开发可省略）

---

## 5. 发现安全问题时的协议

1. **停止**继续堆功能
2. 使用 security review（人工或 `@security-reviewer`）
3. 先修 **CRITICAL**
4. 轮换已暴露 secret
5. 全库检索同类模式

---

## 6. Agent 开发注意

- 勿在对话/日志中粘贴生产密钥
- 改 Security/JWT/权限相关代码后建议专项审查
- Pre-commit secret 扫描（可选，上线前推荐）
