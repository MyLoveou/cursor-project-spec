# 组合式 · 紧凑示例（评测对照）

场景：页面上「估算运费」。**一项能力、一个版本**。

## L2 实现切片

| 切片 | 路径（示意） | 能力 |
|------|--------------|------|
| 算法 | `domain/freight/estimate.ts` | 重量+区号 → 金额或错误码 |
| 功能 | `app/freight/estimateUseCase.ts` | 鉴权、读配置、调算法、映射错误文案 |
| UI | `ui/FreightForm.vue` 或 `.tsx` | 表单与展示，不内嵌费率公式 |
| 组合根 | 订单页 `pages/Order.vue` | 挂上表单，走主路径 |

## 切片契约

| 调用方 | 提供方 | 名称 | 入参 | 出参/错误 |
|--------|--------|------|------|-----------|
| UI | 功能 | `estimateFreight` | `{ weightKg, zone }` | `{ amount }` / `ERR_*` |
| 功能 | 算法 | `calcFreight` | 同上纯数据 | `{ amount }` / 错误码；无 UI 类型 |

## 验收

- 算法：单测边界重量
- 功能：无权限返回码
- 组合根：订单页填表能看到金额
- **不可交付**：只合入 `estimate.ts`
